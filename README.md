# CSP-classwork

中国矿业大学（CUMT）CSP课程大作业。

本仓库用于存放课程实验、课程设计及相关实验报告。

## 实验项目

### 1. Calculator —— 基于 Qt 的简易计算器

使用 **C++ / Qt** 实现的简易计算器，支持连续四则运算，并使用双栈算法完成表达式解析与计算。

**项目内容：**

* Qt 图形化界面
* 四则运算
* 连续表达式计算
* 小数计算
* 括号及运算符优先级处理
* 双栈表达式求值
* 基本输入合法性判断

**相关文件：**

* [Calculator 项目源码](./Calculator/)
* [Calculator 实验报告](./Calculator/REPORT.md)
