# 1 系统概述

本系统基于QT框架以及C++设计并实现了一个图形化简易计算器系统，用户可以根据界面中的数字按钮以及操作符按钮实现如加减乘除取余等简易计算，同时加入表达式合法性检验，在输入不合法时输出报错。

# 2 系统设计

## 2.1 设计目标

实现常规简易计算器的正常简单运算，正确处理不同优先级运算，同时对不合法表达式的异常情况进行报错

## 2.2 设计分析与算法流程

### 定义优先级(priority)

定义**+、-** 优先级为1，***、/、%**优先级为2。优先级越高越优先计算。

### 双栈结构

定义数字栈(numStack)和符号栈(opStack)，流程如下：

- 从左到右扫描表达式，将数字压入数字栈，将运算符根据优先级进行判断。
- 当栈顶运算符优先级高于或等于当前运算符时，先弹出栈顶运算符及相应操作数进行计算，并将计算结果重新压入数字栈；否则将当前运算符直接压入运算符栈。
- 表达式扫描结束后，再依次处理运算符栈中的剩余运算符，最终数字栈栈顶即为表达式的计算结果。
- 同时，程序通过判断负号所在位置，将负数与减法运算符进行区分。

### calculator函数（核心）

函数

```c++
double calculator(stack<double> &numStack,stack<char> &opStack)
```

首先从数字栈中取出两个数字：

```c++
double a=numStack.top();
numStack.pop();
double b=numStack.top();
numStack.pop();
```

然后从运算符栈中取出一个运算符：

```c++
char op=opStack.top();
opStack.pop();
```

最后根据不同的运算符进行计算。

### 特殊情况处理

1. 一元负号处理：

   在calculate()中

   ```c++
   (expression[i]=='-'&&(i==0||
                   expression[i-1]=='+'||
                   expression[i-1]=='-'||
                   expression[i-1]=='*'||
                   expression[i-1]=='/'||
                   expression[i-1]=='%')))
   ```

   用于判断当前的-是否表示负号

2. 除0与求余错误处理：

   对于除法：

```c++
if(fabs(a)<1e-9){
	return NAN;
}
```

​	当除数接近零时，程序返回 NAN。

​	对于求余：

```c++
if(fabs(a)<1e-12){
	return NAN;
}
```

​	同样避免除数为零。

​	最后在等号函数中判断：

```c++
if(isnan(result)){
	ui->lineEdit->setText("Error");
}
```

​	从而在界面中显示错误信息。

## 2.3界面设计

采用常规计算器布局，中间为文本框，左侧为数字区，右侧为操作区

![image-20260920161603356](C:\Users\zhouqinbo\AppData\Roaming\Typora\typora-user-images\image-20260920161603356.png)

QT中使用信号与槽机制实现按钮事件处理。

例如数字按钮：

```c++
connect(ui->btn0, &QPushButton::clicked,this, &MainWindow::numberClicked);
```

当 btn0 被点击后，会发出 clicked 信号，并调用：

```c++
numberClicked()
```

数字 0~9 共用同一个函数。

运算符按钮也采用相同的设计：

```c++
connect(ui->btnAdd, &QPushButton::clicked,this, &MainWindow::operatorClicked);
```

这种设计减少了重复代码，使程序结构更加清晰。

# 4 系统扩展

在常规加减乘除的基础上扩展了求余的功能。

优先级函数(priority)将求余%优先级设为2与*/同级，优先+-进行计算。

考虑到本系统采用的是浮点数计算，calculator函数中取余使用浮点数取余：

```c++
fmod(b,a)
```

输入读取出入栈流程与乘除相同。

# 5 总结

本项目基于 C++ 和 QT框架，实现了一个具有基本数学表达式计算能力的图形化简易计算器。通过本次设计，综合学习运用了 Qt 图形界面开发、信号与槽机制、C++ 函数、字符串处理以及栈等知识。

系统通过 按钮(QPushButton) 实现输入，通过 文本框(QLineEdit) 显示表达式和计算结果，并利用 QT的信号与槽机制将界面操作与后台程序连接起来。

在算法方面，本系统的核心采用数字栈和运算符栈的双栈算法对表达式进行处理。通过设置不同运算符的优先级，使系统能够正确处理类似：3+4*5-6%4/2这样的混合运算。同时，系统还对小数、负数、除零以及基本非法表达式进行了处理，使程序具有一定的可靠性。

通过本次计算器系统的设计与实现，不仅加深了对 C++ 基础知识的理解，也进一步掌握了 Qt 图形界面程序的基本开发方法。特别是在表达式求值过程中，通过栈这一数据结构实现运算符优先级处理，对数据结构在实际程序中的应用有了更加直观的认识。

目前系统也还有一定的扩展空间，例如增加括号、科学计算、历史记录、键盘输入以及更加完善的表达式错误检测等功能。后续可以在现有程序结构的基础上继续完善，使其从一个简单的四则运算计算器逐渐扩展为功能更加完整的科学计算器。

总体而言，本项目基本达到了预期的设计目标，实现了一个结构清晰、操作简单、具有基本错误处理能力的 Qt 图形化计算器，为进一步学习 Qt 应用程序开发以及 C++ 数据结构与算法奠定了基础。
